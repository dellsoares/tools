Imagens para PDF

Agrupe fotos de documentos, páginas escaneadas e imagens em um PDF organizado. Reordene as páginas e baixe o arquivo sem cadastro e sem enviar as fotos para servidores.

PDF de imagens não transforma fotografias em texto selecionável. Se você precisa copiar texto dos documentos, utilize um OCR.

Como criar um PDF com várias imagens?

Selecione até 20 imagens JPG, PNG ou WebP. A ferramenta mostra as miniaturas e permite alterar a ordem antes de montar um único arquivo PDF. As páginas têm formato A4 e as imagens são centralizadas, respeitando suas proporções.

Como a montagem afeta a qualidade?

Para equilibrar tamanho e legibilidade, as imagens são convertidas para JPEG com largura limitada. Isso pode reduzir detalhes de fotografias muito grandes. Páginas com transparência ficam com fundo branco no documento final.

O PDF resultante permite selecionar texto?

Não. As fotos são inseridas como imagens, sem reconhecimento óptico de caracteres (OCR). Para obter texto pesquisável é necessário usar uma ferramenta de OCR separada.

Perguntas frequentes sobre imagens para pdf

Como transformar várias fotos em um PDF?

Selecione ou arraste até 20 imagens, ajuste a ordem com os botões de subir e descer e clique em Criar PDF. Baixe o arquivo resultante.

Posso definir a ordem das páginas do PDF?

Sim. As miniaturas possuem controles para mover cada imagem para cima ou para baixo e para remover arquivos.

O PDF gerado fica no formato A4?

Sim. Cada imagem é dimensionada proporcionalmente para caber em uma página A4, com a margem escolhida.

É possível converter PNG com transparência em PDF?

Sim. A transparência é substituída por fundo branco na página final.

Meus documentos são enviados para algum servidor?

Não. A montagem do PDF acontece no navegador e pode funcionar sem conexão após o carregamento da página.

O texto das fotos pode ser copiado?

Não. Esta versão não tem OCR. O texto permanece como parte da imagem no PDF.
