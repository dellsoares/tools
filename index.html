02 / SOBRE O WS TOOLS

Dúvidas sobre as ferramentas gratuitas

As ferramentas do WS Tools são realmente gratuitas?

Sim. Todas as cinco ferramentas — WhatsApp, contador de palavras, QR Code, Pomodoro e conversor de imagens — são gratuitas e não exigem cadastro.

É necessário instalar algum programa?

Não. As cinco ferramentas funcionam no navegador. O timer Pomodoro também pode ser baixado como arquivo HTML para uso offline no computador.

Posso compartilhar o endereço de uma ferramenta específica?

Sim. Cada ferramenta possui uma página própria. Você pode abrir o endereço diretamente ou utilizá-la pelo catálogo do WS Tools.

O WS Tools guarda os textos, telefones e links informados?

As ferramentas atuais fazem o processamento no próprio navegador e não exigem envio de conteúdo a servidores do WS Tools.
