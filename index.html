02 / SOBRE O WS TOOLS

Dúvidas sobre as ferramentas gratuitas

As ferramentas do WS Tools são realmente gratuitas?

Sim. Todas as 24 ferramentas do WS Tools são gratuitas e não exigem cadastro ou pagamento.

Qual é o limite diário de utilização?

Cada ferramenta oferece até 10 processamentos por dia, contados separadamente no navegador, segundo a data de Brasília. O limite é local e pode ser reiniciado ao limpar os dados ou trocar de navegador.

É necessário instalar algum programa?

Não. As ferramentas funcionam no navegador. O Pomodoro também pode ser baixado como arquivo HTML para uso offline no computador.

Posso compartilhar o endereço de uma ferramenta específica?

Sim. Cada ferramenta possui uma página própria para abrir diretamente e pode ser usada no catálogo WS Tools.

Meus áudios, imagens e documentos são enviados a servidores?

As ferramentas fazem o processamento no navegador. Algumas carregam bibliotecas por CDN; o OCR baixa os dados de idioma e o Separador de Faixas baixa um modelo de IA de aproximadamente 166 MB. Esses downloads não enviam seus documentos ou músicas: os arquivos selecionados permanecem no navegador.
