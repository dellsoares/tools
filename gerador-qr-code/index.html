Como criar um QR Code de link, texto, Wi-Fi ou Pix?

Escreva ou cole o conteúdo, selecione a dimensão e a cor e clique em Gerar QR Code. A imagem aparece na tela, pronta para baixar em PNG. O código pode ser utilizado em impressos, cardápios, apresentações ou materiais digitais.

Link de site: use um endereço completo, como https://exemplo.com.br/, para que o leitor reconheça uma página da web.

Wi-Fi: um formato comum é WIFI:T:WPA;S:MinhaRede;P:MinhaSenha;;, com os dados de sua rede. Para nomes ou senhas com caracteres especiais, podem ser necessários escapes conforme o leitor usado. A senha poderá ser recuperada por quem ler o código.

Pix: cole o código completo de Pix Copia e Cola que foi gerado pelo seu banco. A ferramenta não cria cobranças Pix a partir de chaves e não verifica os dados do recebedor.

Texto: palavras, contatos e instruções também podem ser convertidos. Não inclua informações sigilosas: qualquer pessoa que escanear poderá ler o conteúdo.

O QR Code gerado é estático?

Sim. O conteúdo faz parte da própria imagem, sem depender de um link de redirecionamento do WS Tools. O código não tem prazo de validade próprio, mas o destino pode deixar de funcionar (por exemplo, se um site for removido).

Se o texto ou o endereço mudar, será necessário gerar um novo QR Code. O WS Tools não oferece rastreamento, painel de leitura nem edição remota do conteúdo.

Dúvidas frequentes

É possível criar QR Code grátis, sem cadastro?

Sim. A ferramenta é gratuita, não exige cadastro e gera o arquivo no navegador, com download em PNG.

Como gerar um QR Code para um link?

Cole a URL completa, iniciando por https://, clique em Gerar QR Code e use o botão de download. Teste a imagem com a câmera do celular.

O QR Code criado aqui expira?

Não tem vencimento próprio. É um código estático que armazena os dados diretamente na imagem. O link ou serviço de destino, porém, pode ser alterado ou ficar indisponível.

Posso criar QR Code Pix?

Sim, se você já tiver um código Pix Copia e Cola completo fornecido pelo banco. Basta colá-lo no campo de conteúdo. A ferramenta não cria nem valida cobranças.

O QR Code pode ficar colorido?

Sim. Você pode escolher a cor dos módulos sobre fundo branco. Prefira cores escuras com alto contraste e teste a leitura antes de usar.

Os dados que coloco no QR Code são privados?

O processamento é local e não envia o conteúdo ao WS Tools. Contudo, os dados codificados ficam legíveis para qualquer pessoa que tiver acesso à imagem.
