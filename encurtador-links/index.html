Dúvidas sobre o encurtador de links

É gratuito? Preciso criar uma conta?

O WS Tools usa a API gratuita do is.gd e não exige cadastro. A criação depende da disponibilidade do serviço, que também aplica limites de uso.

Como personalizar meu link?

Digite um final entre 5 e 30 caracteres, usando somente letras, números e sublinhado (_). Exemplo: is.gd/curso2027. Se já estiver ocupado, escolha outro.

Posso editar ou excluir o link depois?

Não. Segundo as regras do is.gd, o link e seu destino não podem ser alterados ou excluídos depois de criados.

O que acontece com o endereço que eu enviar?

Ele é enviado à API do is.gd, que o armazena para criar o redirecionamento. Evite links com informações privadas, senhas ou dados sensíveis. O WS Tools não precisa de conta nem de servidor próprio para isso.
