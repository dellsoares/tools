Como funciona

Aspect ratio é a relação entre largura e altura. Esta calculadora determina as dimensões ideais, mas não altera o arquivo de imagem original.

Dúvidas frequentes

A ferramenta redimensiona o arquivo da imagem?

Não. Calcula as dimensões proporcionais. Para redimensionar a imagem, use o Redimensionador para redes sociais WS.

Qual a diferença entre 16:9 e 9:16?

16:9 é horizontal; 9:16 é vertical. Ambas descrevem a relação largura:altura.
